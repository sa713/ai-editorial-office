# Tutorial

This is a deliverable knowledge profile, not a template or pipeline.

## Purpose

Teach a reader to complete a task or acquire a skill through ordered,
reproducible practice.

## Best Use Cases

- the reader must perform a procedure, not only understand it;
- prerequisites, sequence, checks, and expected results can be defined;
- examples or exercises materially improve learning.

## Weak Use Cases

- exploratory analysis, executive decisions, or non-linear lookup;
- unstable procedures that cannot be verified safely.

## Typical Reader Goal

Complete the target task successfully and understand enough to diagnose common
problems.

## Typical Structure

Prerequisites, goal and expected result, ordered learning steps, checks,
troubleshooting, and next practice.

## Strengths

- directly supports application;
- exposes dependencies and validation points;
- makes learning progress visible.

## Weaknesses

- expensive to verify and maintain;
- linear form is inefficient for experienced repeat users;
- can overfit one environment.

## Common Failure Modes

- steps without explanation;
- missing prerequisites or success checks;
- happy-path-only instruction;
- examples that cannot be reproduced.

## Typical Companion Deliverables

- [Reference](reference.md) for later lookup;
- [Checklist](checklist.md) for repeated execution;
- [Cheat Sheet](cheat-sheet.md) for memory support.

## Not This

A tutorial is not a [Reference](reference.md): it guides a learning sequence
instead of optimizing independent lookup.
