# Ideas

This folder stores ideas, backlog documents, and proposal materials for the AI
editorial office development.

The main file is `master_backlog.md`. It is the only active backlog file for
planning development work and retrospectives of system updates.

Materials in `ideas/` are not production rules. They do not override
`AGENTS.md`, `ai-editorial-office/AGENTS.md`, production roles, pipelines,
templates, or task lifecycle rules.

New ideas may be added here as separate `.md` files, but they do not become
mandatory rules without a separate reviewed system update.
