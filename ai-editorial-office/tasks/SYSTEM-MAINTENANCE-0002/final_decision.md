# Final Decision

Task ID: `SYSTEM-MAINTENANCE-0002`

Decision owner: `chief_editor`

Decision: `accepted`

## rationale

The update strengthens existing review behavior for instructional and operational materials without adding a new framework, role, or stage.

The review system now checks whether a document helps a reader move through an instruction, use sections selectively, avoid useless rereading, and act without reconstructing the process manually.

## accepted changes

- Review Agent responsibilities now include instructional architecture review.
- Review Agent output structure now includes instructional architecture validation.
- Review Pipeline now includes instructional architecture requirements and a quality gate.
- Review task template now includes instructional architecture scaffolds and QA checklist items.
- Forbidden patterns now name structural risks specific to instructions.
- Main deterministic review policy now calls out reading path, section roles, rereading cost, duplication, navigation, and selective reading.

## boundaries

The update does not require compression by default, does not force restructuring, and does not turn every instruction into a checklist. It distinguishes necessary repetition from useless duplication and trust-building explanation from context inflation.
