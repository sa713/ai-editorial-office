# QA Checklist

## Scope

High-governance review checklist for `draft.md`.

| Check | Result | Evidence |
| --- | --- | --- |
| Task has canonical repo task folder | pass | `TASK-CARE-PR-STRATEGY/` under `ai-editorial-office/tasks/` |
| Source boundary recorded | pass | `brief.md`, `sources.md`, `orchestration_plan.md` |
| Risk mode recorded as high-governance | pass | `task-manifest.md`, `status.md`, `orchestration_plan.md` |
| Research artifacts present | pass | `research.md`, `sources.md`, `facts.md`, `claims_table.md` |
| Draft has traceable claims | pass | `claims-used.md` |
| Subjective perception caveated | pass | `draft.md` source boundary section |
| Unsupported official claims excluded | pass | `claims-used.md`, `review.md` |
| Review independence recorded | pass | `review.md` |
| Finalization blocked until review approval | pass | `review.md` outcome approved before finalization |
| Human approval boundary visible | pass | `draft.md`, `status.md`, `final_decision.md` |

## Separate Checklist Rationale

This checklist exists because the selected risk mode is `high-governance`.
It is a verification artifact for Chief Editor governance, not a replacement
for `review.md`.
