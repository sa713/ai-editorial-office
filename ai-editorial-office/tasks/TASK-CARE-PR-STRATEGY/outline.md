# Outline

## Working Title

Care as a legible internal service: strategy after the PR brainstorm

## Reader Path

1. State the editorial decision.
2. Preserve the source caveat.
3. Reframe the problem from "image" to service positioning.
4. Name the strategic principles.
5. Define the workstreams.
6. Give a 30/60/90-day route.
7. Name decisions needed before external rollout.

## Proposed Structure

### 1. Editorial Decision

Core decision: do not start with a PR campaign. Start with a service-positioning
program that makes Care understandable, reachable, visible, and operationally
consistent.

### 2. Source Caveat

The brainstorm is enough for a working hypothesis, not enough for official
organization-wide claims.

### 3. Diagnosis

Problem clusters:

- value is unclear;
- entry points and responsibilities are unclear;
- employee needs are not sufficiently known;
- outputs are not visible or consistently attributed;
- internal Care processes affect communication quality.

### 4. Strategic Principles

- first clarify the service, then amplify it;
- validate needs before promising solutions;
- make Care visible through useful artifacts, not decorative PR;
- treat communications as a product with quality control;
- fix internal operating rhythm where it blocks external clarity.

### 5. Workstreams

1. Service map and responsibility model.
2. UEC needs discovery.
3. Care visibility system.
4. Publication and content quality process.
5. Internal operating rhythm.

### 6. 30/60/90-Day Plan

- Days 1-30: align Care internally and create first service map.
- Days 31-60: validate with UEC segments and pilot visibility mechanics.
- Days 61-90: package portfolio/status format and decide rollout.

### 7. Decisions Needed

- human owner;
- approval boundary;
- first validation audience;
- which artifacts become official.
