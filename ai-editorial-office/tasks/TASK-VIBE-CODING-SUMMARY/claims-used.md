# Claims Used

- Vibe Coding is presented as software creation through natural-language interaction with AI rather than manual line-by-line programming.
  - Source: primary roadmap FAQ; tutorial.

- The roadmap is intended for a mixed audience: beginners/non-programmers who want to build apps and developers who want to use AI coding tools more effectively.
  - Source: primary roadmap FAQ; best-tools guide.

- The document's core problem is unreliable AI-generated code caused by vague prompts, stale context, unreviewed diffs, weak testing, and poor tool fit.
  - Source: primary roadmap; best-practices guide.

- The proposed process is iterative: define intent, give context and examples, ask for a plan, let AI implement in small pieces, review, test, debug, commit, and reset or refresh context.
  - Source: primary roadmap; best-practices guide; tutorial.

- Important skills include prompt engineering, context management, tool selection, Git/version control, debugging, testing, security review, code review, modularity, and workflow standardization.
  - Source: primary roadmap; best-practices guide; best-tools guide.
