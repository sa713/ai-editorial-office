# Outline

## Email

Subject options:

- `Запущен пилот Биржи задач`
- `Биржа задач: где разместить работу, откликнуться или предложить идею`

Structure:

1. Launch signal plus immediate usefulness.
   - Pilot launched in АС Taska.
   - Useful when a task should be visible beyond the immediate circle, when someone can help, or when there is an improvement idea.
2. What this is and what this is not.
   - Common place for tasks, responses, and ideas.
   - Not extra reporting and not a replacement for team agreements.
3. When to use.
   - Publish a task.
   - Respond to a task.
   - Submit an idea.
   - See where colleagues need help.
4. Task vs idea.
   - Task: expected result and agreement.
   - Idea: proposal/observation that first needs consideration.
5. Basic interaction.
   - Author describes work.
   - Employee responds.
   - Response is not automatic assignment.
   - Author chooses Executor and agrees result, deadline, transfer format.
   - Executor completes, Author accepts or requests revision.
   - Ideas are considered separately.
6. Instruction and next step.
   - Link to Task Exchange.
   - Link to detailed instruction.
   - Suggested first action: open To Do, check whether there is relevant task; or create a card if there is task/idea.

## Messenger

Structure:

1. One-line launch signal with personal entry point.
2. Three scan bullets:
   - place a task;
   - take a task;
   - submit an idea.
3. Task vs idea distinction in two lines.
4. Basic rule: response is not assignment; Author chooses and agrees details.
5. Links and next step.
