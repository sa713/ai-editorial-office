# Draft

Основной draft artifact для этой задачи сохранен как:

- `business_requirements.md`

Причина: пользователь явно запросил основной документ с БТ, например `business_requirements.md`. Чтобы не создавать два расходящихся экземпляра одного и того же документа, `draft.md` используется как pipeline-compatible pointer, а review выполняется по `business_requirements.md`.
