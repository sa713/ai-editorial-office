# Proposed Structure

Task ID: `TASK-0003`

Owner: `writer_agent`

Stage: `structure-from-intent`

## structure

1. **Signal**
   Say that issue №13 of `Люди УЭК` is out.

2. **Reader-facing change**
   Name the format shift immediately: not one hero this time, but several young specialists.

3. **Human relevance**
   Explain what this changes for the reader: the issue gives several voices, routes, and working details, so familiar or half-familiar colleagues become a little more visible.

4. **Soft close**
   End with a quiet invitation to read, without pressure, slogans, or artificial enthusiasm.

## structure guardrails

- Do not start with the history of the project.
- Do not define the magazine for readers who already know it.
- Do not turn the announcement into a concept note about the new format.
- Do not use a list of corporate values or HR language.
