# Outline

## 1. Operating Principle

State the core rule: an opening is useful only when it performs an editorial function. Otherwise the message should start with the first useful signal.

## 2. Quick Decision Rule

Give a compact rule for choosing between:

- context opening;
- neutral greeting;
- zero-opening.

## 3. Platform Differences

Separate email and messenger reading modes.

For email:

- subject and preview matter;
- one orienting sentence may help;
- structure can support scanning.

For messenger:

- first line must carry signal;
- greetings usually cost too much;
- shorter patterns are stronger.
