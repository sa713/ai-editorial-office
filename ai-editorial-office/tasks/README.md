# Tasks

Эта папка хранит рабочие задачи редакции и их task-local артефакты.

Она существует, чтобы каждая редакционная или системная задача имела собственную
папку с текущим состоянием, планом, статусом, рабочими файлами и результатами.

Статус папки: активная рабочая зона. При этом старые завершённые задачи внутри
не становятся шаблонами для новых задач.

Читайте конкретную папку задачи, когда работаете с этой задачей, проверяете её
историю, восстанавливаете контекст или сверяете текущий статус.

Не читайте все задачи подряд без причины. Для обычного restart сначала нужен
`task-manifest.md` текущей задачи, а старые задачи читаются только для сравнения,
ретроспективы, доказательства прошлого решения или явной пользовательской
просьбы.

Содержимое задачи может определять активное состояние только этой задачи:
например текущий статус, текущую версию артефакта, ограничения и следующий шаг.
Оно не определяет глобальные правила системы. Глобальная архитектура, роли,
иерархия управления и review-gate остаются в `ai-editorial-office/AGENTS.md`.

## Текущая схема имён

- `TASK-*` — обычные рабочие редакционные задачи.
- `SYSTEM-MAINTENANCE-*` — рабочие записи по обслуживанию и развитию самой
  редакционной системы.

Папки `SYSTEM-MAINTENANCE-*` остаются task-local рабочими записями внутри
`tasks/`, но не должны смешиваться с историческими разборами в `retrospectives/`.
