# Пост для корпоративного мессенджера

Задача застряла, потому что нужны руки или конкретная экспертиза? Идея снова всплыла в разговоре и рискует потеряться в чате?

Для таких случаев запустили пилот Биржи задач в АС Taska.

Можно начать без обязательств: просто открыть Биржу и посмотреть `To Do`. Там видно, какие задачи доступны для отклика и где коллегам может быть нужна помощь.

Биржа пригодится, если:

- задачу нужно показать шире своей команды;
- хочется взять понятную задачу коллег;
- есть идея по улучшению процесса, которую лучше зафиксировать.

Важно: задача - это работа с ожидаемым результатом, идея - предложение на рассмотрение. Отклик не назначает вас автоматически: Автор выбирает Исполнителя и договаривается с ним о результате, сроке и формате передачи.
