# Пост для корпоративного мессенджера

Есть задача, которой нужны руки или конкретная экспертиза? Или идея по улучшению процесса, которую не хочется оставлять в чате?

Для этого запустили пилот Биржи задач в АС Taska.

Туда можно зайти, если:

- есть задача, которую полезно показать шире своей команды;
- хотите взять понятную задачу коллег;
- есть идея по улучшению процесса, и её нужно зафиксировать;
- хочется посмотреть, где сейчас нужна помощь.

Важно: задача — это работа с ожидаемым результатом, идея — предложение на рассмотрение. Отклик на задачу не назначает вас автоматически: Автор выбирает Исполнителя и договаривается с ним о результате, сроке и формате передачи.

Сейчас можно открыть Биржу, посмотреть `To Do` или создать карточку задачи/идеи по инструкции:

- Биржа задач: [ссылка на Биржу задач в АС Taska]
- Инструкция: [ссылка на подробную инструкцию]
