## Source Input

Название:

> Помочь составить опросник защищённости автоматизированных систем (АС)

Исходное описание:

> Прорабатывается идея по анализу защищённости Архитектуры. Для этого нужен опросник для анализа защищённости АС и точек входа с весами распределения (CIA(T)).

Комментарии автора:

- Наработки уже существуют, разработка с нуля не требуется.
- Опросник будут заполнять команды разработки АС.
- Результаты опроса будут загружаться в математическую модель.
- На основании результатов будет рассчитываться уровень защищённости архитектуры.
- Эксперт КА ФО должен получить объективную картину защищённости сопровождаемой архитектуры.
