# Помочь подготовить опросник для оценки защищённости автоматизированных систем

Нужна помощь в доработке опросника, который будет использоваться для анализа защищённости автоматизированных систем и их точек входа. Опросник нужен не как формальная анкета, а как инструмент сбора данных: команды разработки будут его заполнять, а результаты затем будут использоваться в математической модели для расчёта уровня защищённости архитектуры.

## Зачем это нужно

Сейчас прорабатывается подход к оценке защищённости архитектуры. Чтобы такая оценка была не только экспертной, но и более объективной, нужны структурированные входные данные от команд, которые сопровождают автоматизированные системы.

Опросник должен помочь собрать эти данные в едином формате. На его основе профильный эксперт сможет получить более целостную картину защищённости архитектуры и точек входа, а не набор разрозненных комментариев.

## Что предстоит сделать

Нужно помочь превратить существующие наработки в рабочий опросник:

- разобраться в уже подготовленных материалах;
- уточнить структуру опросника для анализа защищённости АС и точек входа;
- сформулировать вопросы так, чтобы команды разработки могли отвечать на них однозначно;
- учесть веса распределения по CIA(T);
- подготовить результат в виде, пригодном для дальнейшей загрузки в математическую модель.

Разработка с нуля не требуется: предварительные материалы уже есть. Основная задача — доработать, структурировать и привести их к формату, который можно использовать в процессе оценки.

## Какой результат ожидается

Итогом должен стать доработанный опросник для команд разработки АС. После заполнения ответы должны давать данные, которые можно передать в математическую модель для расчёта уровня защищённости архитектуры.

Хороший результат позволит:

- собирать сведения о защищённости АС в едином формате;
- учитывать точки входа и связанные с ними аспекты защищённости;
- использовать веса CIA(T) при дальнейшей обработке данных;
- дать эксперту более объективную основу для оценки сопровождаемой архитектуры.

## Кому подойдёт задача

Задача подойдёт участнику, которому интересны архитектура автоматизированных систем, информационная безопасность и формализация экспертных оценок.

Будет полезен опыт или интерес к следующим темам:

- анализ защищённости систем и архитектур;
- работа с опросниками, чек-листами или методиками оценки;
- формулирование понятных вопросов для технических команд;
- структурирование данных для дальнейшей обработки;
- работа с критериями, весами или шкалами оценки.

## Что уже есть

По задаче уже есть предварительные наработки, поэтому начинать с чистого листа не нужно. Участнику предстоит работать с существующими материалами и довести их до применимого формата.

## Что важно уточнить на старте

Перед началом работы стоит уточнить:

- как расшифровывается CIA(T) и что именно означает параметр `T`;
- в каком формате сейчас находятся наработки;
- нужно ли участнику предлагать только вопросы или также шкалы ответов и правила весов;
- какой формат итогового опросника нужен для загрузки результатов в математическую модель;
- можно ли использовать внутренние аббревиатуры в итоговом материале или их нужно заменить понятными формулировками.
