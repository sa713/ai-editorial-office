# Editorial knowledge sources

## Intent / reader usefulness

- **Content design: user needs**  
  Author / organization: GOV.UK / Government Digital Service  
  Link: https://www.gov.uk/guidance/content-design/user-needs  
  Role: Base source for treating content as a response to a valid reader need, action, or task.

- **Content Design**  
  Author / organization: Sarah Richards  
  Link: https://books.google.com/books/about/Content_Design.html?id=T4bxswEACAAJ  
  Role: Practical foundation for designing content around user needs instead of publishing organization-first text.

## Structure / editorial thinking

- **The Pyramid Principle: Logic in Writing and Thinking**  
  Author / organization: Barbara Minto  
  Link: https://www.barbaraminto.com/  
  Role: Structural reference for leading with the answer, grouping arguments, and making logic visible to the reader.

- **Content Strategy for the Web**  
  Author / organization: Kristina Halvorson and Melissa Rach  
  Link: https://books.google.com/books/about/Content_Strategy_for_the_Web.html?id=iK3ItwEACAAJ  
  Role: Governance and strategy source for useful, usable content across creation, publication, and maintenance.

## Web and corporate writing

- **How Users Read on the Web**  
  Author / organization: Jakob Nielsen / Nielsen Norman Group  
  Link: https://www.nngroup.com/articles/how-users-read-on-the-web/  
  Role: Evidence base for scannable structure, concise text, objective language, and inverted-pyramid web writing.

- **Plain Language Guide Series**  
  Author / organization: Digital.gov / U.S. General Services Administration  
  Link: https://digital.gov/guides/plain-language  
  Role: Government-backed plain-language baseline for clear, direct, task-oriented public communication.

- **Everybody Writes**  
  Author / organization: Ann Handley  
  Link: https://annhandley.com/everybodywrites/  
  Role: Practical reference for professional, useful business writing across marketing, editorial, and corporate contexts.

## UX writing

- **Strategic Writing for UX**  
  Author / organization: Torrey Podmajersky  
  Link: https://www.torreypodmajersky.com/content-design-book  
  Role: UX writing source for connecting product words with user goals, business goals, flows, and measurable outcomes.

- **Nicely Said: Writing for the Web with Style and Purpose**  
  Author / organization: Nicole Fenton and Kate Kiefer Lee  
  Link: https://www.nicelysaid.co/  
  Role: Practical guide for humane product and web writing, voice, tone, microcopy, and editorial consistency.

## Russian editorial clarity

- **Пиши, сокращай**  
  Author / organization: Максим Ильяхов, Людмила Сарычева  
  Link: https://bureau.ru/projects/book-pishi/  
  Role: Russian-language baseline for information style, clarity, concision, examples, and editorial discipline.

- **Слово живое и мертвое**  
  Author / organization: Нора Галь  
  Link: https://books.google.com/books/about/%D0%A1%D0%BB%D0%BE%D0%B2%D0%BE_%D0%B6%D0%B8%D0%B2%D0%BE%D0%B5_%D0%B8_%D0%BC%D0%B5%D1%80%D1%82%D0%B2%D0%BE%D0%B5.html?id=Xm4pAQAAIAAJ  
  Role: Classic Russian editorial source against bureaucratic, literal, and lifeless language.

- **Живой как жизнь**  
  Author / organization: Корней Чуковский  
  Link: https://books.google.com/books/about/%D0%96%D0%B8%D0%B2%D0%BE%D0%B9_%D0%BA%D0%B0%D0%BA_%D0%B6%D0%B8%D0%B7%D0%BD%D1%8C.html?id=LEQNAQAAMAAJ  
  Role: Foundational Russian-language reference on living speech, language change, cliche, and bureaucratic distortion.
