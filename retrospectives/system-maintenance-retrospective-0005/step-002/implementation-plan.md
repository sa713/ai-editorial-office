# Implementation plan

## Scope

Add one editorial failure pattern, `Artificial Concept Completion`, to `editorial_knowledge/50_editorial_failure_patterns.md`.

## Steps

1. Inspect the existing failure-pattern structure.
2. Add the new pattern in the existing compact pattern format.
3. Keep the pattern diagnostic, observable, operational, and repair-oriented.
4. Verify that no pipelines, templates, review blocks, confidence marking, workflows, or step 3-5 changes were added.
5. Record decisions, changed files, safety notes, rollback notes, and diff in this step folder.

## Non-goals

- No pipeline changes.
- No template changes.
- No review blocks.
- No confidence marking.
- No new workflow.
- No rewrite of existing failure patterns.
- No research methodology.
- No steps 3-5.
