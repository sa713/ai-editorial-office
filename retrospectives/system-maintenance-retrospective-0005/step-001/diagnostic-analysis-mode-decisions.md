# Diagnostic analysis mode decisions

## Placement

The mode was added to `editorial_knowledge/20_editorial_modes.md`, the preferred file for editorial interaction modes.

No other knowledge file needed edits.

## Mode boundary

`diagnostic_analysis` is defined as a mode for understanding the current state of raw idea materials. It is explicitly separated from writing, review, and design by focusing on diagnosis rather than production, evaluation of finished text, or solution architecture.

## Core decision

The mode asks the editorial system to distinguish:

- what is present in the materials;
- what is implied by the materials;
- what is inferred as an editorial hypothesis;
- what remains unknown or unsupported.

## Recommendation style

Recommendations are limited to material-level clarification, questions, and bounded hypotheses. They must not become a finished product concept, governance model, pilot, roadmap, metric system, lifecycle, or operating model.

## Artificial maturity control

The mode preserves rawness as an object of analysis. It treats uncertainty as a valid output instead of smoothing gaps into confident conclusions.
