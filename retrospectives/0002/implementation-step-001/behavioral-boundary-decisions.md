# Behavioral boundary decisions

## Honesty rule

The following rule is now anchored:

```text
Mandatory stays mandatory.
Optional stays optional.
Unknown stays unknown.
```

Reader-state edits cannot change the real obligation level of the task.

## Optional vs mandatory

If an action is optional, the text must not make it sound required.

If an action is mandatory, the text may make it clearer and less intimidating, but must not make it sound optional.

If a fact is unknown, the text must not imply certainty, activity, popularity, or momentum.

## Reader-state limits

Reader-state awareness is limited to tasks where the reader is asked to enter, try, join, respond, use a workspace, or take a first step that may feel heavier than necessary.

It is not a universal layer for all editorial work.

## Anti-manipulation boundaries

Explicitly disallowed:

- persuasion;
- emotional editing;
- engagement optimization;
- adoption optimization;
- tone policing;
- new workflow;
- new stage;
- new role;
- score;
- required review layer.

## Where reader-state is allowed

Allowed as a bounded editorial sensitivity when it helps:

- make the honest first step clear;
- reduce unnecessary pressure;
- allow observation before commitment when factually available;
- keep language human, operational, and specific.

## Where reader-state is not allowed

Not allowed when it would:

- hide rules;
- soften real obligations into suggestions;
- make optional actions sound required;
- imply activity without evidence;
- add social proof without evidence;
- turn review into tone preference;
- create a behavioral system.
