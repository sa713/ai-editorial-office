# Validation checklist

Use this checklist after any future implementation step.

## Structural checks

- [ ] No new agent was created.
- [ ] No new behavioral pipeline was created.
- [ ] No new lifecycle stage was added.
- [ ] No automatic detector was added.
- [ ] No dashboard or metric artifact was added.
- [ ] No broad template rewrite happened.
- [ ] Pipelines were not changed unless explicitly justified by repeated production evidence.

## Scope checks

- [ ] Reader-state checks remain optional.
- [ ] Reader-state checks are task-type dependent.
- [ ] The change is limited to reader-state friction reduction.
- [ ] No persuasion, engagement, adoption or conversion language was added.
- [ ] No emotional scoring or emotional taxonomy was added.

## Review checks

- [ ] Review did not become tone policing.
- [ ] Review findings tie to reader action, pressure or first-step clarity.
- [ ] Pressure audit is optional for relevant tasks only.
- [ ] Bounded reader-state refinement has explicit re-review scope.

## Governance checks

- [ ] Mandatory clarity was not weakened.
- [ ] Optional actions were not made to sound mandatory.
- [ ] Mandatory actions were not made to sound optional.
- [ ] Unknown facts remain unknown.
- [ ] Reader-state edits do not hide rules, blockers or approval requirements.

## Claims checks

- [ ] No unverified social proof was added.
- [ ] No fake momentum was added.
- [ ] Workspace framing does not invent activity.
- [ ] Any usage/popularity/result claim has evidence.

## Bloat checks

- [ ] Templates did not grow by default.
- [ ] Optional artifacts did not become routine artifacts.
- [ ] The implementation remains smaller than the problem.
- [ ] Iteration 002 did not become wider than first-step friction reduction.
