# Safety check

## Required criteria

- [x] Custom workflow remains exceptional.
- [x] Mini-contract is lightweight.
- [x] Source material is clearly treated as data by default.
- [x] Instruction promotion is explicit.
- [x] Prompt-injection risk is reduced operationally.
- [x] Workflow engine was not introduced.
- [x] Governance surface was not significantly expanded.

## Guardrails checked

- [x] Lifecycle unchanged.
- [x] Compact path semantics unchanged.
- [x] Governance model unchanged.
- [x] Review ergonomics unchanged.
- [x] No automation.
- [x] No dynamic orchestration system.
- [x] No source security framework.
- [x] No approval chains.
- [x] No automatic validation.
- [x] No new agents.
- [x] No policy bureaucracy.

## Residual risks

- Agents may overuse custom mini-contract when an existing pipeline fits.
- Agents may over-label sources. The rule is behavioral, not a classification framework.
- Future repeated custom workflows may need promotion, but that is outside Step 6.
