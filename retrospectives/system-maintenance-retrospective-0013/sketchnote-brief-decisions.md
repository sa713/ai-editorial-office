# Sketchnote Brief Decisions

## Artifact

Added template:

- `ai-editorial-office/templates/artifacts/sketchnote_brief_template.md`

Output artifact:

- `sketchnote_brief.md`

Requested logical path was `templates/artifacts/sketchnote_brief_template.md`.
The actual workspace path follows the existing project structure under
`ai-editorial-office/templates/artifacts/`.

## Source

`sketchnote_brief.md` is built from the article or article draft supplied in the
task.

It does not require `visual_concept.md`, because forcing the sketchnote through
a single visual metaphor would make it behave like an ordinary illustration.

## Ownership

`sketchnote_brief.md` owns the meaning layer for the sketchnote:

- article meaning;
- 4-7 key points;
- author conclusions;
- relationships and hierarchy;
- controlled handwritten content;
- drawing elements;
- forbidden distortions;
- style constraints.

Artist Agent may execute the approved brief but must not change these meaning
decisions.

## Template Shape

The template includes:

- Article meaning;
- Key points;
- Author conclusions;
- Visual hierarchy;
- Suggested layout;
- Handwritten content;
- Drawing elements;
- Do not show;
- Style constraints.

The suggested layout is intentionally loose. It describes one-sheet
organization without becoming a rigid grid or design methodology.
