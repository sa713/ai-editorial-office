# Visual Concept Decisions

## Primary Decision

Create `visual_concept.md` as an editorial artifact type through a new artifact template.

The artifact records understanding of meaning before any artist assignment or prompt preparation.

## Template Location

The template was added to the existing artifact-template folder:

- `ai-editorial-office/templates/artifacts/visual_concept_template.md`

This corresponds to the requested logical path:

- `templates/artifacts/visual_concept_template.md`

## Ownership

`visual_concept.md` is owned by editorial work.

It is not:

- a prompt;
- an artist instruction;
- a composition description;
- a design document;
- a style brief;
- a drawing-technique brief.

## Mode Link

The template is explicitly linked to:

- `visual_illustration_brief`

That mode supplies the semantic extraction behavior; the template stores the resulting visual concept.

## Meaning Layer Only

The template includes only these meaning-layer sections:

- main meaning;
- viewer takeaway;
- emotional tone;
- visual metaphor;
- required elements;
- distortion risks;
- misreading risks;
- notes for a future illustration brief.

## Deferred Work

The template can later inform an illustrator brief or prompt preparation, but Step 3 does not create those downstream artifacts.

Deferred explicitly:

- `image_prompt.md`;
- artist role;
- visual editor role;
- generation workflow;
- storyboard;
- comic artifacts;
- presentation artifacts;
- review heuristics;
- design methodology.
