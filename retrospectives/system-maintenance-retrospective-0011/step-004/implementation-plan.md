# Step 4 Implementation Plan

## Scope

Step: `system-maintenance-retrospective-0011 / step-004`

Focus: bounded review guidance for `visual_concept.md`.

Goal: let editorial review check whether a visual concept preserves and clarifies the text's meaning before any artist, image, or prompt work exists.

## Discovery

The canonical review guidance file is:

- `editorial_knowledge/40_editorial_review_system.md`

The file already contains bounded mode-specific review passes for special modes. Step 4 adds one compact semantic pass for:

- `visual_illustration_brief`;
- especially `visual_concept.md`.

## Implementation Steps

1. Add a bounded semantic visual-concept review pass.
2. Check meaning integrity.
3. Check viewer takeaway integrity.
4. Check metaphor quality.
5. Check distortion.
6. Check misreading risk.
7. Check visual usefulness.
8. Add boundary protection against style, composition, color, drawing technique, artist-skill, and taste discussion.
9. State that revisions should correct the semantic concept, not image execution details.
