# Visual Review Decisions

## Primary Decision

Add bounded review guidance for `visual_illustration_brief` outputs, especially `visual_concept.md`.

The review checks meaning integrity before any image, artist, or prompt exists.

## Review Object

The review object is the semantic concept document:

- `visual_concept.md`

The review object is not:

- an image;
- an artist's work;
- a prompt;
- a design brief;
- a composition plan.

## Review Dimensions

The bounded pass checks:

- meaning integrity;
- viewer takeaway integrity;
- metaphor quality;
- distortion;
- misreading risk;
- visual usefulness;
- boundary protection.

## Boundary Decision

The review must stay editorial, compact, and semantic.

It must not discuss:

- style;
- composition;
- color;
- drawing technique;
- artist skill;
- artistic taste.

## Revision Decision

If review finds a problem, the requested revision should correct the semantic concept.

It should not prescribe image execution, produce prompt wording, direct an artist, or turn the concept into a design-review exercise.
