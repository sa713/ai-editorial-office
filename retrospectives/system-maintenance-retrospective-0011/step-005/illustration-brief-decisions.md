# Illustration Brief Decisions

## Primary Decision

Create `illustration_brief.md` as the next artifact after `visual_concept.md`.

It translates a semantic visual concept into an editorial assignment an illustrator can use.

## Template Location

The template was added to the existing artifact-template folder:

- `ai-editorial-office/templates/artifacts/illustration_brief_template.md`

This corresponds to the requested logical path:

- `templates/artifacts/illustration_brief_template.md`

## Ownership

`illustration_brief.md` is created by editorial work and used by an illustrator.

It does not replace `visual_concept.md`; it is built on top of it.

It is not:

- a prompt;
- a model instruction;
- a design document;
- a composition document;
- a color brief;
- a style brief;
- a drawing-technique guide.

## Difference From Visual Concept

`visual_concept.md` answers:

"What does the illustration mean?"

`illustration_brief.md` answers:

"What should the illustrator draw to carry that meaning?"

## Included Sections

The template includes:

- illustration goal;
- main meaning;
- viewer takeaway;
- emotional tone;
- visual metaphor;
- required elements;
- forbidden distortions;
- misreading risks;
- notes for illustrator.
