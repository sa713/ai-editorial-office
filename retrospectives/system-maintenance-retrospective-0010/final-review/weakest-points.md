# Weakest Points

## Still Heavy

- `AGENTS.md` remains large.
- Pipelines remain long.
- Project navigation file is large and should stay out of normal execution.

## Still Fragile

- Compact mode depends on correct risk classification.
- Manifest freshness is now more important.
- Current-version discipline works only if agents update the pointer.

## Still Noisy

- Pipelines still contain overlapping restart, artifact, and finalization
  language.
- Some old task folders still model the heavy pre-update artifact style.
- Search over the whole repo can still pull old tasks and retrospectives.

## Still Confusing

- Difference between process depth and execution profile may confuse agents.
- Compact handoff vs role handoff vs no finalization handoff needs practice.
- Conditional artifacts require judgment, not just rule-following.

## Still Expensive

- High-governance and source-heavy work remains expensive by design.
- Review can still become costly if it reads broad evidence without a target.
- Editorial knowledge can be over-read if the task mode is not identified first.

## Real Bottleneck

The bottleneck is now judgment:

- when to stay compact;
- when to expand;
- when evidence is enough;
- when review needs separate support artifacts.

That is better than artifact sprawl, but it is still a real operational risk.
