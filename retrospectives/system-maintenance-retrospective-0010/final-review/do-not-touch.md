# Do Not Touch

## Do Not Redesign Governance

Governance survived the update. Changing it now would create more risk than
benefit.

## Do Not Add Agents

Role set is stable enough. New agents would increase routing and review load.

## Do Not Create A Compact Pipeline

Compact execution works because it is a profile inside existing pipelines.
Turning it into a pipeline would create workflow sprawl.

## Do Not Automate Version Discipline

The current pointer rule is enough. A registry, sync tool, database, or scoring
system would be platform creep.

## Do Not Expand Templates Again

Templates are now usable forms. Adding explanatory policy back into them would
undo Step 4.

## Do Not Make QA/Review Summary Mandatory

The main artifact-depth win depends on these staying conditional.

## Do Not Rewrite Role Specs Soon

The compressed role specs are short but still safe. Let production cases test
them before touching them.

## Do Not Normalize Old Task Folders

Legacy folders are history. Updating them would consume effort and risk making
history look like active precedent.
