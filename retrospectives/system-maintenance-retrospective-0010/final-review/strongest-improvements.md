# Strongest Improvements

## Architecture

- Canonical ownership is clearer.
- Roles, templates, pipelines, and global rules now duplicate less.
- Compact execution is official without becoming a new workflow.

## Execution

- Low-risk/simple standard work has a real short path.
- Conditional artifacts are no longer routine.
- Handoff weight is lower.

## Governance

- Review and Chief Editor governance survived compression.
- High-governance expansion triggers remain explicit.
- Compact mode is framed as bounded, not fast-and-loose.

## Restartability

- Short read path reduces restart load.
- Current-version pointer reduces v2/v3/v4 drift.
- Legacy task folders are no longer implicit templates.

## Review

- `review.md` is now the stable center of review.
- Separate QA/summary files remain available only when they add value.
- Review independence and verdict requirements remain visible.

## Token Efficiency

- Role specs and templates became much smaller.
- Fewer service artifacts means fewer files to create, read, and summarize.
- Normal restart no longer implies broad project preload.
