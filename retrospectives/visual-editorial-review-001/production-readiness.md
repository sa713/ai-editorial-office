# Production Readiness

## Current State

Готовность: pilot-ready, not production-ready.

Ветка годится для ручного пилота под контролем Chief Editor. Для штатного использования не хватает operational integration.

## Ten-Task Reality Check

1. Short internal announcement: full chain тяжеловат; нужен compact path.
2. Executive internal announcement: chain полезен, особенно tone/distortion.
3. Article hero illustration: chain работает хорошо.
4. Longread illustration: chain работает, но может потребовать несколько concepts.
5. Educational material: chain полезен, но может захотеться infographic; это надо явно отделять.
6. Complex analytical text: `visual_concept.md` почти обязателен.
7. Community/news post: full chain вероятно слишком дорогой.
8. Sensitive policy material: chain полезен из-за distortion and misreading risks.
9. Product explainer: может пересечься с UX/research; нужен clear source ownership.
10. Abstract opinion piece: высокий риск банальной метафоры; concept review полезен.

## Manual Workarounds Likely

- Chief Editor вручную назначает visual branch.
- Роли вручную игнорируют MVP-only limitation.
- `visual_concept.md` и `illustration_brief.md` вручную объединяют для простых задач.
- Review Agent вручную применяет visual guidance, потому что pipeline не маршрутизирует эти artifacts.

## Production Blockers

- Artist Agent не включён в active role set.
- Нет visual task scaffold.
- Нет минимального orchestration rule для visual branch.
- Нет compact path для low-risk illustration work.

## Ready For

- pilot tasks;
- internal experiments;
- high-value article/longread illustrations;
- controlled manual runs.

## Not Ready For

- unattended production;
- high-volume announcement work;
- workflows where every text automatically needs illustration;
- cases where final image must be semantically accepted without any image-level check.
