# Retrospectives

Эта папка хранит исторические разборы, выводы и материалы развития системы.

Она существует, чтобы сохранить следы уже выполненных разборов: что было
обнаружено, какие решения обсуждались, какие риски или улучшения были замечены.

Статус папки: историческая. Материалы здесь не являются текущими рабочими
задачами редакции.

Читайте эту папку, когда нужен контекст прошлого решения, разбор ошибки,
сравнение старого и текущего поведения или доказательство того, почему изменение
когда-то было принято.

Не читайте эту папку как стартовый контекст для обычной задачи и не используйте
старые разборы как шаблоны для новых рабочих папок.

Содержимое `retrospectives/` не определяет активные правила системы. Если
исторический вывод должен стать правилом, он должен быть явно перенесён в
канонический владелец по иерархии `ai-editorial-office/AGENTS.md`.

## Текущая схема имён

- `system-maintenance-retrospective-*` — исторические разборы работ по
  обслуживанию и развитию редакционной системы.
- `TASK-*-retrospective.md` — исторический разбор конкретной рабочей задачи.

Такие файлы и папки отвечают на вопрос "что система поняла после работы", а не
на вопрос "какая задача сейчас активна".
