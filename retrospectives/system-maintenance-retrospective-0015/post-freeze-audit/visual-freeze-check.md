## Activation behavior

- make an illustration;
- make a visual sketchnote;
- make a handwritten note;
- make an image for this article.

Visual branch may be activated later only if the user explicitly asks to use the visual subsystem, use Artist Agent, launch the visual branch, activate a visual mode, or otherwise clearly asks to run the frozen visual subsystem.
